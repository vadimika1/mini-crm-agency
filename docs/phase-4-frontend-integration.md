# Этап 4. Интеграция frontend с backend

## Цель этапа

Сделать рабочий web-интерфейс на русском языке, который использует реальные endpoint API:

- авторизация пользователя;
- управление сессией;
- загрузка лидов и задач;
- загрузка отчетов для ролей `admin/head`.

## Что реализовано

- Страница `apps/web/app/page.tsx` переведена с заглушек на API-интеграцию.
- Реализован вход в систему:
  - `POST /api/v1/auth/login`
  - обработка ошибок авторизации.
- Реализовано восстановление сессии:
  - хранение `accessToken`/`refreshToken` в `localStorage`;
  - проверка сессии через `GET /api/v1/auth/me`.
- Реализован авто-refresh токена:
  - при `401` выполняется `POST /api/v1/auth/refresh`;
  - после refresh сессия обновляется в браузере.
- Реализован выход:
  - `POST /api/v1/auth/logout`;
  - очистка локальной сессии.
- Реализован дашборд:
  - лиды: `GET /api/v1/leads`;
  - задачи: `GET /api/v1/tasks`;
  - просроченные задачи: `GET /api/v1/tasks?overdue=true`.
- Реализованы отчеты для `admin/head`:
  - `GET /api/v1/reports/funnel`;
  - `GET /api/v1/reports/manager-performance`;
  - `GET /api/v1/reports/proposal-conversion`.
- Добавлен файл окружения frontend:
  - `apps/web/.env.example`
  - `NEXT_PUBLIC_API_BASE_URL=http://localhost:4000`.

## UX и контент

- Весь интерфейс сделан на русском языке.
- Для ошибок, пустых состояний и статусов добавлен понятный текст.
- Добавлены читаемые статусы задач и лидов, бейджи, KPI-карточки.
