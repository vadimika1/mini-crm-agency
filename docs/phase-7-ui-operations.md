# Этап 7. Операционный UI (подэтапы 7.1-7.3)

## Цель подэтапа

Добавить в интерфейс ежедневные операции менеджера без перехода в API-клиент:
- создание лида;
- редактирование ключевых полей лида;
- создание и редактирование задач;
- быстрое завершение задач.

## Что реализовано

- В блоке `Канбан лидов`:
  - добавлена кнопка `Новый лид`;
  - добавлена форма `POST /api/v1/leads` с полями компании, контакта, email, телефона, сайта, приоритета и даты follow-up.
  - добавлены фильтры и быстрый поиск:
    - по этапу,
    - по приоритету,
    - по ответственному (включая `Без ответственного`),
    - по тексту (компания/контакт/email/телефон),
    - счетчик `Показано X из Y` и сброс фильтров.
  - добавлены массовые действия по выделенным лидам:
    - массовое назначение ответственного (`POST /api/v1/leads/:id/assign`),
    - массовая смена приоритета (`PATCH /api/v1/leads/:id`),
    - массовый перенос этапа (`POST /api/v1/leads/:id/stage-transitions`).
  - добавлены операционные шорткаты:
    - `Выделить все по фильтру`,
    - `Снять выделение`.
- В карточке лида 360 на вкладке `Обзор`:
  - сохранен блок быстрого редактирования (`follow-up` + `priority`);
  - добавлен отдельный блок `Основные данные лида` с сохранением через `PATCH /api/v1/leads/:id`.
- В блоке `Задачи`:
  - добавлена кнопка `Новая задача`;
  - добавлена форма `POST /api/v1/tasks` с выбором лида и обязательными полями;
  - добавлено редактирование выбранной задачи через `PATCH /api/v1/tasks/:id`;
  - добавлено быстрое завершение задачи через `POST /api/v1/tasks/:id/complete`.
- В интерфейсе добавлены:
  - русские сообщения ошибок валидации для форм;
  - компактные действия по задаче (`Изменить`, `Завершить`) в списках задач.
  - русская локализация статуса сделок (`Открыта`, `Выиграна`, `Потеряна`) в табе `Сделки и КП`.
