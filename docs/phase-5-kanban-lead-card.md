# Этап 5. Канбан лидов и карточка лида

## Цель этапа

Перевести работу с лидами в визуальный операционный режим:

- канбан-доска со всеми этапами воронки;
- drag-and-drop переходы между этапами;
- карточка лида с деталями и историей изменений этапов.

## Что реализовано

- Backend:
  - добавлен endpoint `GET /api/v1/leads/stages`;
  - endpoint отдает активные этапы воронки (по умолчанию для default pipeline);
  - endpoint доступен авторизованным пользователям.
- Frontend:
  - добавлен блок "Канбан лидов" с горизонтальными колонками этапов;
  - карточки лидов можно перетаскивать между колонками;
  - переход этапа выполняется через `POST /api/v1/leads/:id/stage-transitions`;
  - если обязательные поля этапа не заполнены, ошибка отображается в UI;
  - по клику на лид открывается карточка лида:
    - ключевые поля лида;
    - история переходов (`GET /api/v1/leads/:id/history`).
- UI/UX:
  - интерфейс полностью на русском;
  - доска адаптируется под мобильный экран с горизонтальным скроллом;
  - активная карточка лида визуально выделяется.
