# Этап 6. Карточка лида 360

## Цель этапа

Сделать полноценную рабочую карточку лида, чтобы менеджер мог работать с контекстом сделки в одном месте.

## Что реализовано

- В карточку добавлены вкладки:
  - `Обзор` — ключевые поля лида + история переходов этапов;
  - `Бриф` — создание, редактирование и завершение брифа;
  - `Сделки и КП` — список сделок лида и их коммерческих предложений;
  - `Активности` — единая лента событий по лиду.
- Вкладка `Бриф`:
  - поддерживает `POST /api/v1/leads/:leadId/brief` при первом сохранении;
  - поддерживает `PATCH /api/v1/leads/:leadId/brief` при обновлении;
  - поддерживает `POST /api/v1/leads/:leadId/brief/complete`.
- Для ускорения загрузки карточки добавлены API-фильтры:
  - `GET /api/v1/deals?lead_id=:id`;
  - `GET /api/v1/tasks?lead_id=:id`.
- Во вкладке `Обзор` добавлен блок "Быстрое редактирование лида":
  - поле `next follow-up`;
  - поле приоритета;
  - сохранение через `PATCH /api/v1/leads/:id`.
- Лента `Активности` собирается из:
  - истории этапов;
  - событий брифа;
  - сделок и их закрытия;
  - отправленных КП;
  - задач по лиду.
